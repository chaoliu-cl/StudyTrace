# App Review materials

`app-review-response.txt` is the current combined Apple reply. Complete the
reviewer-invitation and hosted-video placeholders using the steps in
`build13-submission-preparation.txt` before submitting it.

The validation JSON contains coordinate-free background-location evidence.
Physical-device recordings and the `diagnostics/` directory are intentionally
excluded from Git because they can reveal location history and device details.
Keep them locally and provide the required recording privately to App Review;
do not publish it through this public repository.

`build13-verification.txt` records completed checks and their limitations.
The longer draft and background-location notes preserve the supporting context.
