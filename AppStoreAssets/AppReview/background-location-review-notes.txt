Conclusion

Retain UIBackgroundModes/location for StudyTrace's ongoing mobility-history
feature. The implementation uses the standard location service to collect
consenting participants' movement history while they use other apps, and
exposes daily collected locations under Dashboard > Location. That standard
background service requires the location background mode. The need to preserve
mobility history between foreground sessions is the feature to explain to App
Review. The study's requested coverage should also be explained in its consent
and reviewer access information.

Build 11 now has verified fresh background persistence on a physical iPhone.
The configuration retains a 300-meter movement filter, approximately
hundred-meter requested accuracy, and a three-minute minimum sampling interval.
Those settings do not guarantee an update every three minutes. Significant-
change monitoring or regions would be suitable for a feature limited to coarse
moves or boundary crossings; they do not offer the same configurable stream of
standard location updates used by the current mobility-history implementation.

Build 11 repair and checks

The old positive-interval storage path depended on NSTimer saving a cached
location. Build 11 saves accepted Core Location fixes in the delegate callback,
uses acquisition timestamps, rate-limits by fix time, and rejects invalid,
duplicate, or older fixes within a sensor session. Receipt audit events retain
application state without duplicating coordinates. The sensor now also stops
its significant-change monitor when stopped. Permission descriptions explain
the mobility-history feature. A Podfile hook preserves the vendored AWARE fix
through dependency reinstalls.

Four location regression tests were added; all 14 unit tests passed. The signed
Release build compiled and passed signature verification, was installed over
build 8 preserving user data, and the device reports build 11. The delivery MP4
passed a complete decode check. Info.plist lint, Podfile syntax, dependency
patch applicability, and git diff whitespace checks passed.
